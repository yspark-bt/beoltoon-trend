# 🍯 벌툰 콘텐츠랩 — 가맹점 마케팅 숏폼 발굴 도구

YouTube Data API v3로 한국 YouTube Shorts를 분석해, **벌툰 매장에서 그대로 따라 찍을 수 있는 콘텐츠**만 골라서 보여주는 정적 웹사이트입니다.

가맹점·본사 마케팅 담당자가 "이번 주에 뭘 찍어야 할지" 고민할 필요 없이, 지금 뜨는 포맷 중 매장에서 바로 재현 가능한 것만 추천받고 촬영 가이드까지 자동으로 받을 수 있습니다.

**GitHub Pages**에서 바로 호스팅되며, 별도 서버·백엔드 없이 브라우저만으로 동작합니다.

---

## 🎯 이 도구의 목적

벌툰 방문객이 실제로 좋아하는 콘텐츠 5가지를 기준으로 분석합니다.

| 방문 목적 | 관련 콘텐츠 |
|------|------|
| 놀러오기 | 혼놀 브이로그, 친구·모임 놀거리 |
| 데이트 | 커플 데이트 코스, 아지트 추천 |
| OTT 시청 | 넷플릭스·티빙·웨이브·디즈니플러스 드라마·영화·예능 추천 |
| 만화책·웹툰 | 만화책·웹툰 추천·리뷰·정주행 |
| 보드게임 | 보드게임 카페, 보드게임 브이로그 |

단순히 "인기 있는 콘텐츠"가 아니라, **가맹점이 매장에서 그대로 촬영할 수 있는 포맷**(🏪 매장 촬영 가능 표시)을 우선적으로 상위에 노출합니다.

## 📋 주요 기능

| 기능 | 설명 |
|------|------|
| **따라 찍기 TOP 15** | 추천도 · 순위 변동(▲▼NEW) · 매장 촬영 가능 뱃지 표시 |
| **아코디언 상세 보기** | 항목 클릭 시 원본 영상 + 분석 + 촬영 가이드가 바로 아래 펼쳐짐 |
| **매장 촬영 가이드** | 포맷별(공간투어형·보드게임형·혼놀형·데이트형 등) 구체적 촬영 방법 자동 생성 |
| **선점 아이템** | 16~22위 성장 초기 콘텐츠 — 다른 가맹점보다 먼저 시도 가능 |
| **촬영 가이드 TOP 3** | 가장 따라 찍기 쉬운 상위 3개의 단계별 기획안 |
| **6시간 캐시** | API 쿼터 절약 — 재방문 시 저장된 결과 즉시 표시 |
| **순위 변동 추적** | 이전 분석 결과와 비교해 변동폭 자동 계산 |

## 🔑 YouTube Data API v3 Key 발급

1. [Google Cloud Console](https://console.cloud.google.com) 접속
2. 새 프로젝트 생성
3. **API 및 서비스 → 라이브러리** → `YouTube Data API v3` 검색 → **사용 설정**
4. **API 및 서비스 → 사용자 인증 정보** → **API 키 만들기**
5. (권장) **API 키 제한 → HTTP 리퍼러** → `https://yspark-bt.github.io/*` 추가

> ⚠️ Public 레포에 키가 노출되므로 리퍼러 제한을 꼭 설정하세요.

### API 쿼터 안내

| 작업 | 소모 단위 |
|------|-----------|
| 카테고리 수집 (videos.list) | ~4 units |
| 관심사별 보완 검색 (search.list × 46개 쿼리) | ~4,600 units |
| 역추출 키워드 추가 검색 (search.list × 12개) | ~1,200 units |
| 통계 보강 (videos.list) | ~35 units |
| **1회 분석 총 소모** | **약 5,839 units** |
| 일일 무료 한도 | **10,000 units** |
| **하루 최대 분석 횟수** | **약 1회** |

> ⚠️ OTT 4개 플랫폼(넷플릭스·티빙·웨이브·디즈니플러스) × 영화·드라마·예능 × 추천·인기 조합(24개 쿼리)이 추가되어 쿼터 소모가 커졌습니다. 커버리지를 넓히는 대신 하루 분석 횟수가 줄었습니다.
>
> 💡 6시간 캐시 기능이 있어 재방문 시 API를 다시 호출하지 않습니다.

## ⚙️ 추천도(점수) 계산 방식

```
추천도 = 조회수 × 0.45
       + 좋아요 × 8 × 0.20
       + 댓글 × 20 × 0.10
       + 신선도(최근 3일 이내 비율) × 0.10
       + 참여율((좋아요+댓글)/조회수) × 0.10
       + 매장 재현 가능 보너스 × 0.05
→ 0~100으로 정규화, 영상 단위로 중복 없이 순위화
```

**매장 재현 가능 보너스**란 제목에 "이색카페", "룸카페", "혼놀", "데이트", "보드게임카페" 등의 단어가 포함된 콘텐츠에 부여되는 가중치입니다. 단순 인기도가 아니라 **실제로 따라 찍을 수 있는지**를 반영합니다.

## 🏪 매장 재현 가이드 종류

| 포맷 | 촬영 방법 |
|------|------|
| 공간 투어형 | 매장 입구~룸~좌석~소품을 훑는 워크스루 촬영 |

| 동네 핫플 소개형 | "동네 숨은 핫플" 훅으로 외관~내부 소개 |

## 🔒 개인정보 & 보안

- API Key는 **브라우저 localStorage에만 저장** — 서버로 전송되지 않습니다
- 분석 결과 캐시도 localStorage에만 저장
- GitHub Pages는 정적 호스팅 — 서버사이드 코드 없음

## 🐞 자주 묻는 문제

**Q. "API Key가 유효하지 않다"는 에러가 나요**
→ Google Cloud Console에서 YouTube Data API v3가 **활성화**되어 있는지 확인하세요.

**Q. quotaExceeded 에러가 나요**
→ 일일 쿼터(10,000 units)를 초과했습니다. 태평양 표준시 자정에 초기화됩니다.

**Q. 웨일에서는 되는데 크롬에서 API Key 자동 입력이 안 돼요**
→ 브라우저별로 localStorage가 분리되어 있습니다. `js/app.js`의 `DEFAULT_API_KEY`가 최신 버전인지 확인하고 강력 새로고침(Ctrl+Shift+R)하세요.

**Q. 결과에 매장 재현 가능 콘텐츠가 안 보여요**
→ `js/youtube-api.js`의 `REPLICABLE_FORMAT_KEYWORDS`에 원하는 키워드를 추가하세요.
